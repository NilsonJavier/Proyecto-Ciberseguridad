# Proyecto de Ciberseguridad

## Descripción del proyecto

Este proyecto tiene como propósito aplicar herramientas de control de versiones y automatización de procesos mediante Git, GitHub y GitLab.

Se realizarán pruebas de inicialización de repositorios, seguimiento de cambios, sincronización de archivos y configuración de procesos CI/CD.

## Objetivos

- Configurar un repositorio local con Git.
- Publicar el proyecto en GitHub.
- Importar el repositorio a GitLab.
- Configurar un pipeline de integración y despliegue continuo.
- Verificar el funcionamiento de las etapas de preparación, pruebas y despliegue.

## Herramientas utilizadas

- Git
- GitHub
- GitLab
- GitLab CI/CD
